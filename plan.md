Project Name: ChainStrike

Overview:
ChainStrike is a plug-and-play RWA (Real World Asset) infrastructure platform built on :contentReference[oaicite:0]{index=0}. It enables issuers to tokenize real-world assets, enforce compliance, and launch tradable markets using an orderbook-based exchange.

The core focus is to build a compliant, orderbook-driven RWA marketplace with strong liquidity and investor access.

---

CORE IDEA:

A platform where:
- Issuers create and launch RWA tokens
- Markets are created using orderbooks (not AMMs)
- Verified investors trade assets like a real financial exchange

---

SYSTEM ACTORS:

1. Issuers
- Asset owners (gold, real estate, etc.)
- Tokenize and launch assets

2. Investors
- Verified users (KYC)
- Trade and invest in RWAs

3. Platform
- Provides infra, compliance, and orderbook trading

---

FULL FLOW:

STEP 1: Issuer Onboarding
- Signup
- KYB verification
- Wallet connection

STEP 2: Asset Creation
- Create token (ASA on Algorand)
- Define supply and metadata

STEP 3: Compliance Setup
- Whitelisting
- Investor restrictions

STEP 4: Orderbook Setup (Liquidity Creation)
- Issuer places initial orders:

Example:
Sell: 100 tokens @ ₹100
Buy (optional): ₹10,000 @ ₹98–₹100

- Funds are locked
- Orderbook initialized

STEP 5: Market Launch
- Market goes live
- Orderbook visible
- Matching engine activated

STEP 6: Trading
- Investors place orders
- System matches orders
- Trades settle on-chain
